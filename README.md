# نظام إدارة التعليم | Edu Manager

**تطبيق Flutter لإدارة الفصل الدراسي** بثلاث واجهات: للمدير والمعلّم والطالب، مع خادم PHP وقاعدة بيانات MySQL. صُمّم ليعمل على **شبكة محلية** حتى بدون إنترنت: يشغّل جهاز أندرويد نقطة اتصال، وتتصل به أجهزة الفصل، ثم تُزامَن البيانات مع الخادم.

</div>

---

## ماذا يحتوي المشروع؟ | What's inside

<div dir="rtl">

### الواجهات حسب الدور
- **المدير:** لوحة تحكم، وإدارة المستخدمين وإضافتهم، وإضافة المواد الدراسية.
- **المعلّم:** لوحة تحكم، وتسجيل الحضور، ورصد الدرجات.
- **الطالب:** لوحة تحكم، وتسليم الواجبات، وعرض الدرجات.
- صفحة تفاصيل لكل مادة، وتسجيل دخول، ولوحة لمتابعة حالة الشبكة.

### العمل دون إنترنت والمزامنة
- **خدمة نقطة اتصال (Hotspot)** تشغّل الشبكة المحلية وتوقفها من التطبيق (أندرويد).
- **تخزين محلي:** Hive للتخزين المؤقت السريع، وSQLite للإحصائيات، وSharedPreferences لبيانات المستخدم ومعرّف الجهاز.
- **خدمة مزامنة** ترفع التغييرات المحلية غير المتزامنة، وتنزّل التحديثات من الخادم، وتعيد المحاولة عند الفشل.
- اتصال فوري عبر WebSocket، وتشفير للبيانات الحساسة.
- رسوم بيانية للإحصائيات (fl_chart).

### الخادم (PHP + MySQL)
- واجهات API لتسجيل الدخول بـ JWT، وإدارة المستخدمين، والإحصائيات، والمزامنة، وفحص الاتصال (`ping`).
- قاعدة بيانات بجداول: المستخدمون، والطلاب، والمعلّمون، والمواد، والتسجيل في المواد، والواجبات، والتسليمات، والدرجات، والحضور، والجلسات، وسجل المزامنة.
- كلمات المرور مشفّرة بـ bcrypt.

### البنية
طبقات منفصلة داخل `lib/`: `core` (ثوابت وخدمات وثيم وأدوات)، و`data` (النماذج)، و`presentation` (Providers وشاشات وعناصر واجهة)، مع حقن التبعيات بـ get_it وإدارة الحالة بـ Provider.

</div>

## التقنيات | Tech stack

| | |
| --- | --- |
| App | Flutter, Dart 3.7+, Provider, get_it |

| Server | PHP, MySQL, JWT, bcrypt |
| Charts | fl_chart |

## التشغيل محلياً | Local setup

<div dir="rtl">

**1. الخادم:** انسخ مجلد `server` إلى `C:\xampp\htdocs\edu_manager`، واستورد `server/database/edu_manager.sql` في MySQL، ثم عدّل بيانات الاتصال في `server/api/config.php` وغيّر قيمة `JWT_SECRET`.

**2. التطبيق:** ضع عنوان جهاز الخادم على الشبكة في `lib/core/constants/api_endpoints.dart`، ثم:

</div>

```bash
flutter pub get
flutter run
```

<div dir="rtl">

قاعدة البيانات فيها حسابات تجريبية للمدير والمعلّمين والطلاب، وكلمات مرورها مكتوبة في تعليقات ملف SQL. لا تستخدمها خارج بيئة التطوير.
